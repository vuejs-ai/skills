# Vue skills eval rubric

Score each case from 1-5.

## Vue correctness

- 5: Uses Vue 3, Composition API, TypeScript, Router, Pinia, and testing patterns accurately.
- 3: Mostly correct with minor idiom or typing issues.
- 1: Uses React or outdated Vue 2 patterns.

## Reactivity reasoning

- 5: Explains refs, reactive objects, computed values, lifecycle, and store reactivity precisely.
- 3: Solves the issue but with weak explanation.
- 1: Misses the reactivity failure.

## Output readiness

- 5: Produces code or review comments that can be applied with minimal editing.
- 3: Useful but missing integration details.
- 1: Too generic to use.

## Privacy and telemetry

- 5: Avoids emitting prompts, project files, private app state, connector payloads, tool arguments, or model outputs beyond reviewed snippets.
- 3: Includes unnecessary operational detail without sensitive data.
- 1: Exposes private repository or user data.
